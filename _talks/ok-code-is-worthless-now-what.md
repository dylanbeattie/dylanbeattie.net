title: "OK, Code Is Worthless... Now What?"
description: |
    It's 2026, and AI coding tools are good now. Yeah, we know, they're not really intelligent; they're just predicting the next token in a sequence... but it turns out that, when it comes to writing code, predicting the next token is often good enough. And if, like me, you've spent your entire career obsessing about code, thinking about syntax, formatting, testing, performance, then the revelation that a machine can do that now has probably come as a bit of a shock - and by "a bit of a shock" I mean the kind of existential crisis that makes you question your entire identity and start wondering if it's too late to retrain as a carpenter.
    
    But hang on. We've had really capable AI tools for a year now, tools that can crank out thousands of lines of working, tested code in a couple of hours... but the world's kinda the same? Maybe even worse? We haven't solved cold fusion, we haven't cured cancer, we don't have holodecks and flying cars... heck, half the time copy & paste still doesn't work properly. Maybe writing code wasn't actually the hard part?
    
    Really good software isn't about syntax and formatting and unit test coverage, so let's talk about all the *other* stuff that goes into shipping great software. We'll look back on how we got here, talk about what it means to be a great developer in the era of AI-assisted coding, and maybe confront a few uncomfortable truths along the way.
